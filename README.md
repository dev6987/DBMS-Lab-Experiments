## About This Repository

Welcome to my DBMS Laboratory repository!

This repository contains all 10 experiments performed as part of the Database Management Systems laboratory course.

It includes SQL source code, experiment documentation, practical implementations, and relevant certification credentials.

The purpose of this repository is to demonstrate practical knowledge of database design, SQL programming, relational database concepts, transaction management, normalization, indexing, and query optimization.
