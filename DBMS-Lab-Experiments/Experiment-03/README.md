# Experiment 3 – Employee, Department and Project Database

## Aim
Create an Employee–Department–Project schema, insert at least 30 employees across 5 departments and 8 projects, and demonstrate SQL queries.

## Required SQL concepts
1. Selection
2. Projection
3. Aggregate functions
4. `GROUP BY`
5. `HAVING`
6. `CASE` expressions
7. `ORDER BY`

## Suggested files
- `experiment-03.sql` – database, tables, sample data and queries.
- `experiment-03-record.pdf` – practical record.
- `output/` – genuine query-output screenshots.

## Verification checklist
- [ ] At least 30 employee records are inserted.
- [ ] 5 departments are represented.
- [ ] 8 projects are represented.
- [ ] All seven listed SQL concepts are demonstrated.
- [ ] Query outputs are checked and captured.

## Run order
Run this experiment before Experiments 4, 5 and 6 if those scripts reuse the Employee–Department–Project schema.
