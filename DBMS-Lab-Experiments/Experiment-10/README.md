# Experiment 10 – Query Optimization

**Aim:** Generate at least 10,000 rows, analyze five less-optimized queries using `EXPLAIN`, apply indexes and query rewrites, and compare execution behavior.

## What the script does
- Creates `QueryOptimizationDB.sales_analytics`.
- Generates exactly 10,000 rows.
- Demonstrates five less-optimized query patterns.
- Creates indexes on date, region, region/price, customer, product and quantity.
- Rewrites queries using date ranges, equality predicates, pre-aggregation, `UNION`, and sargable predicates.
- Includes optional `EXPLAIN ANALYZE` statements for MySQL 8.0.18+.

## Run and document
1. Execute the full SQL file in MySQL 8.0+.
2. Record `EXPLAIN` details before and after optimization (`type`, `possible_keys`, `key`, `rows`, `Extra`).
3. Use your SQL client's elapsed-time display or `EXPLAIN ANALYZE` to record actual timings.
4. Compare results as well as performance. The rewrite for Query 2 uses `IN ('North','South')`, which is equivalent to the original suffix condition for the four region values generated by this script.
5. Do not invent execution-time numbers; use the measurements from your own run.

**Note:** Optimizer decisions and timings vary by MySQL version, hardware, cache state, and statistics.
